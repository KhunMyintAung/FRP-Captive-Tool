# 📱 FRP Captive Tool

**FRP Captive Tool** သည် Android စမတ်ဖုန်းများ၏ Factory Reset Protection (FRP) ကျော်လွှားခြင်း (Bypass) လုပ်ငန်းစဉ်များတွင် Captive Portal နည်းပညာကို အသုံးပြု၍ Browser နှင့် System Settings များသို့ လွယ်ကူလျင်မြန်စွာ ဝင်ရောက်နိုင်ရန် ဖန်တီးထားသော Mobile Service Tool တစ်ခု ဖြစ်ပါသည်။

---

## ✨ အဓိက လုပ်ဆောင်ချက်များ (Features)
* **လျင်မြန်လွယ်ကူမှု:** Wi-Fi Captive Portal မှတစ်ဆင့် ဖုန်း၏ Browser (Chrome / Samsung Internet) သို့ တိုက်ရိုက် ချိတ်ဆက်ဖွင့်လှစ်ပေးနိုင်ခြင်း။
* **အသုံးပြုရ လွယ်ကူခြင်း:** ရှုပ်ထွေးသော အဆင့်များ မလိုအပ်ဘဲ ဖုန်းပြုပြင်ရေး (Mobile Service) ပညာရှင်များအတွက် လုပ်ငန်းတွင်ကျယ်စေရန် ဒီဇိုင်းထုတ်ထားခြင်း။
* **ကျယ်ပြန့်စွာ အသုံးပြုနိုင်မှု:** Android ဗားရှင်း အမျိုးမျိုးနှင့် Brand အစုံတွင် စမ်းသပ်အသုံးပြုနိုင်ခြင်း။

---

## 💻 လိုအပ်ချက်များ (Requirements)
* Windows 10 / Windows 11 PC
* Wi-Fi Adapter (Hotspot သို့မဟုတ် Local Network ချိတ်ဆက်ရန်)
* USB Cable (လိုအပ်ပါက ADB / MTP ချိတ်ဆက်ရန်)
